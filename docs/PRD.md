# Just Do It — Product overview

**Status:** Working draft  
**Product:** Just Do It  
**Vision:** Make AI agent skills portable, discoverable, versioned, and trustworthy for developers who self-host.  
**Audience:** Individual developers and small teams using AI coding agents  
**Model:** Open-source, self-hosted

## Purpose

Just Do It is an MCP server and skill catalog you run yourself. Agents connect with a bearer token, search and retrieve skills, optionally use recommendations and project memory, and optionally sync skills into Claude Code or Cursor skill folders.

## Principles

- Validate problems before expanding scope.
- Keep the open-source core useful on its own.
- Prefer deterministic, source-backed behavior.
- Treat skill content as untrusted instructions (do not execute skill scripts).
- Prefer small, reversible changes.

## Success

Developers can install the server, authenticate, discover and retrieve skills, and keep using the workflow because it saves time.
